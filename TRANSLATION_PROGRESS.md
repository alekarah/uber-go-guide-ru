## 📖 Глоссарий терминов

Для единообразия перевода используются следующие термины:

| Английский | Русский | Примечание |
|------------|---------|------------|
| slice | слайс | Не "срез" |
| map | map | Без перевода, как устоявшийся термин |
| interface | интерфейс | — |
| struct | структура | — |
| pointer | указатель | — |
| receiver | приёмник | — |
| goroutine | горутина | — |
| channel | канал | — |
| mutex | мьютекс | — |
| defer | defer | В контексте ключевого слова без перевода |
| panic | panic | В контексте функции без перевода |
| nil | nil | Без перевода |
| zero value | нулевое значение | — |
| embedded type | встроенный/встраиваемый тип | В зависимости от контекста |
| shadowing | затенение (переменной) | — |
| linting | линтинг | — |
| container | контейнер | Для slice, map, channel |
| wrapping | оборачивание | В контексте ошибок |
| assertion | приведение типов | Для type assertion |
| pattern | паттерн | — |
